# Fix Human Sleep: Funniest Patch Note

One line of patch notes, written in deadpan changelog voice, announcing that
human sleep has been fixed. The bug being resolved is the 3 AM replay of every
embarrassing thing since 2009 — it has been moved to business hours.

## How to run

```sh
python3 main.py
```

This writes the patch note (a single line, 98 characters) to
`/output/entry.txt`, creating the directory if needed. Python standard
library only.
